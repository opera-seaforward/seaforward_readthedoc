We use a ready-made, published dataset already on disk:

```
~/seaforward/data/DATASETS_CROCOTOOLS/RUNOFF_DAI/Dai_Trenberth_runoff_global_clim.nc
```

It contains the monthly-mean discharge of the **925 largest rivers on Earth**, each with
its mouth longitude/latitude and name. The Niger, Ogooué, Sanaga and other Gulf-of-Guinea
rivers are all in it.

To **look inside** the file and confirm it is there, type:

```bash
conda activate seaforward
ncdump -h ~/seaforward/data/DATASETS_CROCOTOOLS/RUNOFF_DAI/Dai_Trenberth_runoff_global_clim.nc | head -30
```

`ncdump -h` prints the "header" (the list of variables) of a NetCDF file. You should see
variables like `FLOW_clm` (the monthly climatology, in m³/s) and `lon_mou`/`lat_mou`
(the river mouth positions).
