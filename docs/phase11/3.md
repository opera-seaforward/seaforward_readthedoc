The tool `dai_rivers.py` reads **your grid** and picks out the Dai rivers whose mouths
fall inside it. You do not edit the script — everything goes on the command line.

```bash
conda activate seaforward
cd ~/seaforward/forecast/scratch/Canary_12/CROCO_FILES
python ~/seaforward/sftools/download/dai_rivers.py croco_grd.nc ./DAI_RIVERS/
```

The arguments:

- `croco_grd.nc` — your model grid; the tool reads its lon/lat bounds automatically
- `./DAI_RIVERS/` — the folder the river files are written to

```text
Grid bounds from croco_grd.nc:
  lon -22.15 .. -15.35   lat 13.94 .. 24.04
  (margin 0.6 deg, Qmin 300.0 m3/s)
Selected 1 rivers:
name                   lon     lat   ann_m3/s
Senegal             -16.25   16.25      692.3
Wrote 1 river .txt files + river_list.txt to ./DAI_RIVERS/
```

It echoes the grid bounds it read and the two thresholds it applied, then lists what it
found. It also creates `DAI_RIVERS/` containing one `.txt` file per river — the daily
discharge for a year — and `river_list.txt`, the list the runoff builder reads.

```bash
ls DAI_RIVERS/
cat DAI_RIVERS/river_list.txt
```

**One river is the honest answer here.** The Canary domain runs from 14°N to 24°N along
the Saharan and Mauritanian coast, where there is very little runoff. The Senegal, at
692 m³/s, is the only Dai river of any size inside it.

!!! warning
    **Check whether a river you expected is missing.** The **Gambia** is the obvious candidate on this coast, and it is absent — its mouth sits near 13.5°N, just south of the grid's 13.94°N edge. The `margin` setting accepts mouths up to 0.6° outside the grid, but a mouth that far out cannot be placed on a grid cell and would be dropped later anyway.

    If a river you need is missing, extend the grid to include its mouth rather than widening the margin.

**Changing which rivers are included.** The tool takes two optional numbers:

```bash
python .../dai_rivers.py croco_grd.nc ./DAI_RIVERS/ <Qmin> <margin>
```

`Qmin` is the minimum discharge in m³/s — higher means fewer, bigger rivers — and
`margin` is how far outside the grid edge, in degrees, a mouth may sit. The defaults
are 300 and 0.6, as the tool's own output confirms.

Lowering `Qmin` changes nothing here — running with `100` returns the same single
river, because there is genuinely nothing else in the domain above that threshold. On a
wetter coast it would bring in several more.
