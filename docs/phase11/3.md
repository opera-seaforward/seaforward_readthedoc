The tool `dai_rivers.py` reads **your grid** and picks out the Dai rivers whose mouths
fall inside it. You do not edit the script — everything goes on the command line.

```bash
conda activate seaforward
cd ~/seaforward/forecast/scratch/IGOG_12/CROCO_FILES
python ~/seaforward/sftools/download/dai_rivers.py croco_grd.nc ./DAI_RIVERS/
```

The arguments:

- `croco_grd.nc` — your model grid; the tool reads its lon/lat bounds automatically
- `./DAI_RIVERS/` — the folder the river files are written to

```text
Grid bounds from croco_grd.nc:
  lon 3.94 .. 12.56   lat -6.04 .. 5.54
  (margin 0.6 deg, Qmin 300.0 m3/s)
Selected 10 rivers:
name                   lon     lat   ann_m3/s
Congo                12.75   -5.75    39857.9
Niger (Issa Ber       6.25    4.75     5700.1
Ogooué                9.75   -0.75     4688.7
Sanaga               10.25    3.75     1984.7
Kouilou              11.75   -4.25      905.8
Cross                 9.25    5.75      541.8
Nyanga               10.25   -2.75      517.0
Nyong                10.12    3.57      446.3
Niari                13.08   -4.11      379.2
Wouri                 9.97    4.46      308.5
Wrote 10 river .txt files + river_list.txt to ./DAI_RIVERS/
```

It echoes the grid bounds it read and the two thresholds it applied, then lists what it
found. It also creates `DAI_RIVERS/` containing one `.txt` file per river — the daily
discharge for a year — and `river_list.txt`, the list the runoff builder reads.

```bash
ls DAI_RIVERS/
cat DAI_RIVERS/river_list.txt
```

!!! warning
    **Not every river in the list survives into the runoff file.** The `margin` accepts mouths up to 0.6° outside your grid, and those cannot be placed on a grid cell. Compare the bounds the tool printed — `lon 3.94 .. 12.56`, `lat -6.04 .. 5.54` — against the mouths it selected: **Congo** at 12.75°E, **Cross** at 5.75°N and **Niari** at 13.08°E all fall outside. The runoff file ends up with seven rivers, not ten.

    The Congo is the largest river in the region at nearly 40,000 m³/s, so losing it matters. If a river you need is being dropped, extend the grid to include its mouth rather than shrinking the margin.

**Changing which rivers are included.** The tool takes two optional numbers:

```bash
python .../dai_rivers.py croco_grd.nc ./DAI_RIVERS/ <Qmin> <margin>
```

`Qmin` is the minimum discharge in m³/s — higher means fewer, bigger rivers — and
`margin` is how far outside the grid edge, in degrees, a mouth may sit. The defaults
are 300 and 0.6, as the tool's own output confirms.
