`cppdefs.h` is CROCO's list of compile-time switches. Rivers need three of them.

```bash
cd ~/seaforward/forecast/scratch/IGOG_12
nano cppdefs.h
```

Press **Ctrl+W** to search, type `Point Sources`, press Enter. That lands on the river
section of your config. Make it read:

```c
                      /* Point Sources - Rivers */
# define PSOURCE
# define PSOURCE_NCFILE
# ifdef PSOURCE_NCFILE
#  undef PSOURCE_NCFILE_TS
# endif
```

So: `PSOURCE` and `PSOURCE_NCFILE` change from `undef` to `define`, and
`PSOURCE_NCFILE_TS` **stays `undef`**.

!!! important
    **Why `PSOURCE_NCFILE_TS` stays undefined.** The runoff file carries **flow only** — no temperature or salinity. Turn this switch on and CROCO looks for river temperature and salinity in the file, fails to find them, and stops. Left undefined, it reads a fixed value for each from `croco.in` instead, which is the next step.

Save and exit: **Ctrl+O**, Enter, **Ctrl+X**. Then check:

```bash
grep -n "PSOURCE" cppdefs.h | head
```

!!! note
    **There may be two river sections.** A large `cppdefs.h` carries a block for each example configuration. Only the block belonging to **your** config — the one before the next `#elif defined ...` — is compiled. If a second `Point Sources - Rivers` block appears further down under a different config name, leave it alone.
