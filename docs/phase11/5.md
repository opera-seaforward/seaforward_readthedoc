`cppdefs.h` is CROCO's list of compile-time switches. Rivers need three of them.

```bash
cd ~/seaforward/forecast/scratch/Canary_12
grep -n "PSOURCE" cppdefs.h | head -6
```

```text
289:# undef PSOURCE
290:# undef PSOURCE_NCFILE
291:# ifdef PSOURCE_NCFILE
292:#  undef PSOURCE_NCFILE_TS
580:# define PSOURCE
581:# undef  PSOURCE_MASS
```

The first block — here lines 289 to 292 — is your config's. Line 580 belongs to a
different configuration further down the file; leave it alone.

```bash
nano cppdefs.h
```

Press **Ctrl+W** to search, type `Point Sources`, press Enter. That lands on the river
section of your config. Make it read:

```c
                      /* Point Sources - Rivers */
# define PSOURCE
# define PSOURCE_NCFILE
# ifdef PSOURCE_NCFILE
#  undef PSOURCE_NCFILE_TS
# endif
```

So `PSOURCE` and `PSOURCE_NCFILE` change from `undef` to `define`, and
`PSOURCE_NCFILE_TS` **stays `undef`**.

!!! important
    **Why `PSOURCE_NCFILE_TS` stays undefined.** The runoff file carries **flow only** — no temperature or salinity. Turn this switch on and CROCO looks for river temperature and salinity in the file, fails to find them, and stops. Left undefined, it reads a fixed value for each from `croco.in` instead, which is the next step.

Save and exit: **Ctrl+O**, Enter, **Ctrl+X**. Then check:

```bash
sed -n '289,293p' cppdefs.h
```

```text
# define PSOURCE
# define PSOURCE_NCFILE
# ifdef PSOURCE_NCFILE
#  undef PSOURCE_NCFILE_TS
# endif
```

!!! note
    **`PSOURCE` appears more than once.** A large `cppdefs.h` carries a block for each example configuration, and only the block belonging to **your** config — before the next `#elif defined ...` — is compiled. That is why the `grep` above comes first: it tells you which line numbers are yours before you start editing.
