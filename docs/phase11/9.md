Because a climatology is built **once** and reused, rivers are simpler than tides. The
driver `run_forecast_cycle.sh` has a `--rivers` flag that, each cycle, **copies** the
pre-built `croco_runoff.nc` into the run folder, the same way it copies the grid. It
does not regenerate anything.

```bash
./run_forecast_cycle.sh --tides --rivers        # parent, tides + rivers
```

The flag also selects the matching pre-built binary. Names are built as
`croco_` + `plain|1way|2way` + `_tides` + `_rivers`, so this run needs
`croco_plain_tides_rivers`. Phase 3 documents the full matrix.

**Runs stay in separate folders.** The output folder carries the same tags as the
binary, so a run with rivers and a run without land in different places and never
overwrite each other:

```text
model-runs/Canary_12/20260711_plain_tides/          # --tides           (no rivers)
model-runs/Canary_12/20260711_plain_tides_rivers/   # --tides --rivers  (with rivers)
```

That makes a clean **river versus no-river comparison** straightforward — run the same
date both ways, and any difference is the rivers:

```bash
./run_forecast_cycle.sh --tides --rivers --date 2026-07-11   # with rivers
./run_forecast_cycle.sh --tides          --date 2026-07-11   # without rivers
```

By hand, the two runs write to the same `CROCO_FILES/croco_his.nc`, so save the first
before rebuilding — the warning in Step 5.

Check the two cover the same window before comparing:

Then plot them, marking the river mouth so you can tell a plume from anything else:

```bash
cd ~/seaforward
python3 << 'PYEOF'
import matplotlib; matplotlib.use('Agg')
import matplotlib.pyplot as plt, xarray as xr, numpy as np
from matplotlib.colors import ListedColormap

B = 'forecast/scratch/Canary_12/'
a = xr.open_dataset(B + 'CROCO_FILES/croco_his.nc', decode_times=False)   # tides only
b = xr.open_dataset(B + 'with_rivers/croco_his.nc', decode_times=False)   # + rivers

sa = a.salt.isel(time=-1, s_rho=-1).where(a.mask_rho == 1)
sb = b.salt.isel(time=-1, s_rho=-1).where(b.mask_rho == 1)
d  = sb - sa
print('no rivers: min %.2f   rivers: min %.2f   largest freshening %.3f PSU'
      % (float(sa.min()), float(sb.min()), float(d.min())))

vmin, vmax = 34, 37        # the plume goes below 34; extend='min' marks that
lim  = 0.5                 # fixed, not a percentile: with one river most of the
land = ListedColormap(['0.8'])   # domain is unchanged and a percentile scales to noise

fig, ax = plt.subplots(1, 3, figsize=(17, 6), constrained_layout=True)
for k in range(3):
    ax[k].pcolormesh(a.lon_rho, a.lat_rho,
                     np.where(a.mask_rho.values == 0, 1, np.nan),
                     cmap=land, vmin=0, vmax=1)
    ax[k].set_aspect('equal'); ax[k].set_xlabel('longitude')

ax[0].pcolormesh(a.lon_rho, a.lat_rho, sa, cmap='viridis', vmin=vmin, vmax=vmax)
ax[0].set_title('tides only')
h2 = ax[1].pcolormesh(a.lon_rho, a.lat_rho, sb, cmap='viridis', vmin=vmin, vmax=vmax)
ax[1].set_title('tides + rivers')
fig.colorbar(h2, ax=ax[:2], label='salinity (PSU)', shrink=0.8, pad=0.02, extend='min')

h3 = ax[2].pcolormesh(a.lon_rho, a.lat_rho, d, cmap='BrBG', vmin=-lim, vmax=lim)
ax[2].plot(-16.25, 16.25, 'k^', ms=8, mfc='none', mew=1.5)
ax[2].annotate('Senegal', (-16.25, 16.25), textcoords='offset points',
               xytext=(7, 4), fontsize=9)
ax[2].set_title('rivers - no rivers')
fig.colorbar(h3, ax=ax[2], label='dS (PSU)', shrink=0.8, pad=0.02, extend='both')

ax[0].set_ylabel('latitude')
fig.savefig('docs/img/rivers_salinity.png', dpi=110)
PYEOF
```

![Surface salinity with and without rivers](../img/rivers_salinity.png)

*Surface salinity at the end of the run, with and without river forcing, and the
difference with the Senegal's mouth marked. The two salinity panels share a colour
scale; the difference has its own.*

The first two panels look almost identical, which is the honest result — a river is a
**local** effect, and the domain-wide salinity field is set by the boundaries and the
atmosphere. Note that both panels show fresh water near 16.5°N and again at the
southern edge: that comes from the boundary conditions, not the river, which is exactly
why the difference panel is needed to isolate what the river did.

**The difference sits on the marker.** The freshening concentrates at the Senegal's
mouth and spreads a short way along the coast — the plume, and nothing else in the
domain moves by a comparable amount. The scattered specks elsewhere are the two runs'
eddies diverging slightly, which any pair of runs with different forcing will show.
