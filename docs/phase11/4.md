Now we turn `river_list.txt` into `croco_runoff.nc`, the file CROCO reads. The builder
must be run **from the `prepro` folder**, so it can find its helper modules.

```bash
conda activate seaforward
cd ~/seaforward/sftools/croco_pytools/prepro
python make_river_run.py \
    --input_dir ~/seaforward/forecast/scratch/Canary_12/CROCO_FILES/DAI_RIVERS/ \
    --croco_dir ~/seaforward/forecast/scratch/Canary_12/CROCO_FILES/ \
    --Yorig 2000 --Ystart 2000 --Mstart 1 --Yend 2000 --Mend 12 \
    --rivers_cyl 365.25 --file_format FULL
```

The backslashes let one command span several lines. Type it all, or put it on one line
without them.

The arguments:

- `--input_dir` — the `DAI_RIVERS/` folder from Step 1
- `--croco_dir` — where your grid is, and where the output goes
- `--Yorig 2000` — the model's year origin, which must match your CROCO setup
- `--rivers_cyl 365.25` — **the important one**: makes the file a repeating yearly
  cycle. Without it the forecast could not find the right day in a later year.

Along the way it places each river mouth on a grid cell, and says so:

```text
Look for the closest non-masked point ...
Choose a default value for runoff direction
Correction of the position of the rivers ...
-- Optimisation du positionnement --
Senegal.txt
i:  69.0
j:  31.0
River positionned in sea
i2:  69
j2:  31
make_river_run: wrote .../croco_runoff.nc (cycle=365.25, 1 rivers) + for_croco_in.txt
```

**`River positionned in sea`** is the line to look for. The Dai mouth position is a
real-world coordinate that may land on a land cell once snapped to your grid, so the
builder searches for the nearest wet cell and reports where it ended up. Here the
Senegal went to (69, 31).

Two files are now in `CROCO_FILES/`:

- **`croco_runoff.nc`** — the river forcing CROCO reads
- **`for_croco_in.txt`** — the text block you paste into `croco.in` in Step 4

**Check the runoff file:**

```bash
cd ~/seaforward/forecast/scratch/Canary_12/CROCO_FILES
ncdump -h croco_runoff.nc | grep -E "n_qbar|cycle_length"
python3 -c "
import xarray as xr
d = xr.open_dataset('croco_runoff.nc')
print([str(n) for n in d.runoff_name.values])
"
```

```text
n_qbar = 1 ;
qbar_time:cycle_length = 365.25 ;
['Senegal.txt']
```

`cycle_length = 365.25` confirms the yearly cycle, and `n_qbar` gives the number of
rivers that made it in. **Compare that against Step 1's list.** They match here, but a
river whose mouth sits outside the grid is listed by `dai_rivers.py` and then dropped
by this builder, so a smaller `n_qbar` than you expected is worth investigating before
going further.
