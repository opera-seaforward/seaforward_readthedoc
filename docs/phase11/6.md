`croco.in` is CROCO's run-time settings file. It needs the list of rivers.

First look at the block the builder generated:

```bash
cat ~/seaforward/forecast/scratch/IGOG_12/CROCO_FILES/for_croco_in.txt
```

It holds a `psource_ncfile:` block with your rivers' grid indices. Now open `croco.in`:

```bash
cd ~/seaforward/forecast/scratch/IGOG_12
nano croco.in
```

Search with **Ctrl+W** for `psource_ncfile` and replace the existing block, using your
own indices from `for_croco_in.txt` but with the two changes below:

```text
psource_ncfile:   Nsrc  Isrc  Jsrc  Dsrc qbardir  Lsrc  Tsrc   runoff file name
    CROCO_FILES/croco_runoff.nc
                 7
                         29  127  1  -1   T T   26.0  0.0
                         65   69  0  -1   T T   26.0  0.0
                         67  121  0   1   T T   26.0  0.0
                         93   21  0  -1   T T   26.0  0.0
                         76   39  0  -1   T T   26.0  0.0
                         72  114  0  -1   T T   26.0  0.0
                         70  123  0   1   T T   26.0  0.0
```

Two changes from the raw `for_croco_in.txt`:

**The path.** Use the short `CROCO_FILES/croco_runoff.nc` rather than the full path the
builder writes, so it still resolves when the file is staged into each run folder.

**Temperature and salinity** — the last two numbers on each row. Set them to `26.0` and
`0.0`: 26 °C and 0 PSU. The zero salinity is the whole point, since this is fresh
water. The builder's default of 14 °C and 5 PSU is too cold and too salty for tropical
rivers; pick values suited to your own region.

Save and exit: **Ctrl+O**, Enter, **Ctrl+X**. Then check:

```bash
grep -A12 "^psource_ncfile:" croco.in
```

The count on the third line must match the number of rows below it, and both must match
the `n_qbar` from Step 2 — seven here.
