`croco.in` is CROCO's run-time settings file. It needs the list of rivers.

First look at the block the builder generated:

```bash
cat ~/seaforward/forecast/scratch/Canary_12/CROCO_FILES/for_croco_in.txt
```

```text
Line to enter in the croco.in file in the psource_ncfile section :
-----------------------------------------------------------------
psource_ncfile:   Nsrc  Isrc  Jsrc  Dsrc qbardir  Lsrc  Tsrc   runoff file name
                     /home/you/seaforward/forecast/scratch/Canary_12/CROCO_FILES/croco_runoff.nc
                   1
                          69    31   0      -1    T T  14.0  5.0
```

Those grid indices — 69 and 31 — are where the builder placed the Senegal's mouth in
Step 2. Now open `croco.in`:

```bash
cd ~/seaforward/forecast/scratch/Canary_12
nano croco.in
```

Search with **Ctrl+W** for `psource_ncfile` and replace the existing block, using your
own indices but with the two changes below:

```text
psource_ncfile:   Nsrc  Isrc  Jsrc  Dsrc qbardir  Lsrc  Tsrc   runoff file name
    CROCO_FILES/croco_runoff.nc
                 1
                         69    31   0      -1    T T   24.0  0.0
```

Two changes from the raw `for_croco_in.txt`:

**The path.** Use the short `CROCO_FILES/croco_runoff.nc` rather than the full path the
builder writes, so it still resolves when the file is staged into each run folder.

**Temperature and salinity** — the last two numbers on the row. The builder's defaults
are 14 °C and 5 PSU. Change them to something appropriate for your river: 24 °C and
0 PSU here. The zero salinity is the whole point, since this is *fresh* water; leaving
5 PSU means the model injects brackish water and the plume is weaker than it should be.

!!! warning
    **Check what is already in that block.** A config that has been used for other experiments may carry a stale river list — a different count and different indices from a domain you no longer have. Replace the whole block, not just the numbers you notice.

Save and exit: **Ctrl+O**, Enter, **Ctrl+X**. Then check:

```bash
grep -A5 "^psource_ncfile:" croco.in
```

```text
psource_ncfile:   Nsrc  Isrc  Jsrc  Dsrc qbardir  Lsrc  Tsrc   runoff file name
    CROCO_FILES/croco_runoff.nc
                 1
                         69    31   0      -1    T T   24.0  0.0
```

The count on the third line must match the number of rows below it, and both must match
the `n_qbar` from Step 2 — one here.
