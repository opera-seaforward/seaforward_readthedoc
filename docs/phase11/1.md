Rivers pour **freshwater** into the ocean. Near the coast this lowers the salinity,
creates buoyant **river plumes**, and changes how the water is layered. A model that
ignores rivers gets its coastal salinity wrong.

CROCO adds rivers as **point sources**: at chosen grid cells it injects a volume of
water per second, in m³/s, with a chosen temperature and salinity. The job is to:

1. get river discharge data for the region,
2. turn it into a file CROCO understands, `croco_runoff.nc`,
3. tell CROCO to use it — edit two config files, recompile,
4. make it run automatically every forecast, with the `--rivers` flag.

We use a **climatology** — the typical seasonal discharge, repeating every year — so
the forecast always has valid river data for any date without downloading anything
live.
