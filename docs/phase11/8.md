Before wiring rivers into the automatic system, run a short test. The cleanest way is to
let the driver assemble it — it handles the atmosphere and the dates correctly:

```bash
cd ~/seaforward/forecast
./run_forecast_cycle.sh --tides --rivers
```

The `--rivers` flag is covered in full further on in this chapter.

The line that proves the rivers are being read:

```text
GET_PSOURCE -- Read Run-off flow fields      for time =    206.5
GET_PSOURCE -- Read Run-off flow fields      for time =    207.5
GET_PSOURCE -- Read Run-off flow fields      for time =    208.5
```

CROCO opened `croco_runoff.nc` and found what it expected. Those times are **days into
the climatology's yearly cycle**, not model days — day 206 is late July, matching the
cycle date. They advance one per day as the run proceeds.

If the step table then keeps printing finite numbers — kinetic energy steady, `trd = 0`,
no `NaN` — the rivers are running stably. The run ends with `MAIN: DONE`, one per grid.

A second check is the salinity itself. Rivers should be visibly freshening the water
near their mouths:

```bash
cd ~/seaforward
python3 << 'PYEOF'
import xarray as xr, numpy as np
D = 'forecast/model-runs/IGOG_12/20260726_plain_tides_rivers/fcst/CROCO_FILES/'
d = xr.open_dataset(D + 'croco_his.nc', decode_times=False)
s = d.salt.isel(time=-1, s_rho=-1).where(d.mask_rho == 1)
print('surface salinity: min %.2f  max %.2f  mean %.2f'
      % (float(s.min()), float(s.max()), float(s.mean())))
PYEOF
```

A minimum well below the open-ocean value — around 35 for the Gulf of Guinea — is the
rivers doing their job. If the minimum sits at the ambient value, nothing is being
injected.
