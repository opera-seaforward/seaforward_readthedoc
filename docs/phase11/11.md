- **River names with accents** — Ogooué, for instance. The Dai file uses Latin-1 text
  encoding. The tool handles it; if you write your own reader, decode with `latin-1`.
- **`PSOURCE_NCFILE_TS` must stay `undef`** — the runoff file carries flow only, and
  temperature and salinity come from `croco.in`.
- **Two `cppdefs.h` river blocks** — edit only the one in *your* config's branch.
- **Rivers on the coast** can land on awkward cells. The SEA-FORWARD copy of the builder
  carries fixes the stock tool lacks for grids where this happens.
- **Rivers near an open boundary** — the Congo sits just outside IGOG's south-east
  corner, and Step 1 shows it being dropped for that reason. Extending the grid to
  include such a mouth is one option; the other is to let that water enter through the
  boundary condition instead, which is what the parent product already carries.
