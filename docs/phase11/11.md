- **River names with accents** — the Dai file uses Latin-1 text encoding, so names like
  Ogooué or Sénégal can come back garbled. The tool handles it; if you write your own
  reader, decode with `latin-1`.
- **`PSOURCE_NCFILE_TS` must stay `undef`** — the runoff file carries flow only, and
  temperature and salinity come from `croco.in`.
- **`PSOURCE` appears more than once in `cppdefs.h`** — edit only the block in *your*
  config's branch. Run `grep -n "PSOURCE" cppdefs.h` before opening the editor.
- **A stale `psource_ncfile` block** — a config used for earlier experiments may carry
  river indices from a domain you no longer have. Replace the whole block, not just the
  numbers you notice.
- **Rivers on the coast** can land on awkward cells. The builder searches for the
  nearest wet cell and prints where it ended up — `River positionned in sea` — so check
  those indices against your grid.
- **A river just outside the domain** — the Gambia's mouth sits a little south of
  Canary's 13.94°N edge and does not appear at all. Extending the grid to include the
  mouth is one option; the other is to let that water enter through the boundary
  condition, which the parent product already carries.
