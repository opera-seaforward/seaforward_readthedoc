- **River names with accents** (Ogooué): the Dai file uses Latin-1 text encoding. Our
  tool already handles this; if you write your own reader, decode with `latin-1`.
- **`PSOURCE_NCFILE_TS` must be `undef`** — flow-only data; T/S comes from `croco.in`.
- **Two `cppdefs.h` river blocks** — edit only the one in *your* config's branch.
- **Rivers on the coast** can land on tricky cells; the SEA-FORWARD copy of the builder
  fixes three bugs in the stock tool that otherwise crash on such grids.
- **Rivers near the open boundary** (e.g. the Congo at the SE corner of IGOG) are better
  left to enter via the boundary than injected as a point source — see the technical
  reference for the reasoning.
