Before wiring rivers into the automatic system, it is wise to run a short test. The
cleanest way is to **let the automatic driver do it** (it assembles the atmosphere and
dates correctly). See the companion chapter *Running Forecasts Automatically* for the
`--rivers` flag. In brief:

```bash
cd ~/seaforward/forecast
./run_forecast_cycle.sh --tides --rivers
```

While it runs, the key line that proves the rivers are working is:

```
GET_PSOURCE -- Read Run-off flow fields   for time = ...
```

That message means CROCO successfully read your `croco_runoff.nc`. If the model then keeps
printing time-step lines (numbers that stay finite, not `NaN`), the rivers are running
stably.
