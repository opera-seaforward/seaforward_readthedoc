`croco.in` is CROCO's run-time settings file. It needs the list of rivers.

First, **look at the block the builder generated** for you:

```bash
cat ~/seaforward/forecast/scratch/IGOG_12/CROCO_FILES/for_croco_in.txt
```

You'll see a `psource_ncfile:` block with your rivers' grid indices. Now open `croco.in`:

```bash
cd ~/seaforward/forecast/scratch/IGOG_12
nano croco.in
```

Search (**Ctrl+W**) for `psource_ncfile`. Replace the existing block so it reads (using
**your** rivers' indices from `for_croco_in.txt`, but note the two changes below):

```
psource_ncfile:   Nsrc  Isrc  Jsrc  Dsrc qbardir  Lsrc  Tsrc   runoff file name
    CROCO_FILES/croco_runoff.nc
                 7
                         29  127  1  -1   T T   26.0  0.0
                         65   69  0  -1   T T   26.0  0.0
                         67  121  0   1   T T   26.0  0.0
                         93   21  0  -1   T T   26.0  0.0
                         76   39  0  -1   T T   26.0  0.0
                         72  114  0  -1   T T   26.0  0.0
                         70  123  0   1   T T   26.0  0.0
```

Two things to change from the raw `for_croco_in.txt`:

1. **The path** — use the short `CROCO_FILES/croco_runoff.nc` (not the long full path), so
   it works when the file is staged into each run folder.
2. **Temperature and salinity** — the last two numbers on each row. Set them to
   **`26.0  0.0`** (26 °C, 0 PSU). Salinity **0** is the whole point — this is *fresh*
   water. The builder's default of 14 °C / 5 PSU is too cold and too salty for tropical
   rivers.

Save and exit: **Ctrl+O**, **Enter**, **Ctrl+X**.
