The switches in `cppdefs.h` only take effect when you rebuild the model. On this system,
the NetCDF library comes from the conda environment, so compile **with the environment
active**:

```bash
cd ~/seaforward/forecast/scratch/IGOG_12
conda activate seaforward
./jobcomp 2>&1 | tee compile_rivers.log
```

`./jobcomp` runs the build script. `2>&1 | tee compile_rivers.log` shows the output on
screen **and** saves it to a file you can re-read. Compiling takes a few minutes. Success
looks like a little ASCII crocodile and the message:

```
CROCO is OK
```

This produces a fresh `croco` binary that knows about rivers.
