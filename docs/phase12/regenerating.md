The diagram is generated by `seaforward_architecture.py` and can be regenerated
with any component highlighted — useful when walking through one stage at a time
in teaching:

```python
from seaforward_architecture import draw
draw(out='img/seaforward_architecture.png')            # the whole system
draw(highlight=['engine','driver','restart'],          # the operational loop
     out='img/arch_operational.png')
draw(highlight=['repo'], out='img/arch_repo.png')      # the reproducibility layer
```
